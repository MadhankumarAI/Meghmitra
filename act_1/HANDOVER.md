# Mungaru WhatsApp bot: what was built, how to run it, what's left

*Status as of 19 September 2026. For the full technical reference (API contracts, languages, voice, licences),
see `README.md`.*

---

## 1. What this is

The last stage of the Mungaru monsoon early-warning system. The forecasting pipeline decides
**what** warning to send. This service **delivers it to farmers on WhatsApp**, in their own language, as:

- a **picture card**: alert colour, verdict, 4-week outlook tiles, 3 steps, the Mungaru logo;
- a **text message** with buttons;
- a **voice note** reading it aloud.

Nothing reaches a farmer until an **agriculture officer approves** the advisory.

Farmers sign up by **tapping**, not typing, like the Namma Metro WhatsApp bot.

These were tested on the Meta test number **+1 555-143-2024**, with the phone +91 90194 10439.

- **Sign-up by taps:**

- **STOP / START** to unsubscribe and resubscribe, and "hi", "menu" or "ನಮಸ್ಕಾರ" to bring up the menu, in any language.
- **Advisories:** posted, **held for officer approval**, then delivered as card, voice note, text and buttons.
  The log showed `sent → delivered → read`.

- **Fixed public address** through ngrok (free): `https://unmixed-mollusk-puppy.ngrok-free.dev`.
  Meta's webhook points here permanently.

### Built and tested on the laptop

- **6 languages:** Kannada, Hindi, Telugu, Tamil, Marathi and English.
  - Translated offline with AI4Bharat **IndicTrans2**, free.
  - Checked automatically for broken placeholders and WhatsApp length limits.
  - Crop names were hand-entered.
- **Voice notes** from AI4Bharat **Indic Parler-TTS**, running free on the laptop's GPU. They take about 2–8 minutes each, and are made while the advisory waits for approval.
- **Officer console connection:** `GET /dispatch/log` and `GET /dispatch/summary` for the other team's web console, plus `/preview` so an officer can see the Kannada card before approving.
- **Phone simulator** at `http://127.0.0.1:8000/dev/phone`, to demo without a phone.
- **Preflight check:** `scripts\doctor.py` finds most setup problems and says how to fix each one.
- **Translator review sheets:** `scripts\review_sheet.py` exports and imports Excel-friendly files for native speakers.
- **56 automated tests**: `.venv\Scripts\python -m pytest -q`.

### Decisions taken

| Decision | Why |
|---|---|
| **SMS removed completely** | Your call. The brief's "Done means" step 3 (real SMS) is therefore deliberately not met. It's recorded in README §4, and mKisan is the route if SMS is ever needed. |
| **ngrok** instead of the Cloudflare quick tunnel | The address never changes, so Meta's webhook is set once. |
| Messages use pictures and small icons | Makes the bot look like the Metro bot, and be easier to use. |
| Nothing is generated by AI at send time | All wording is prepared and checked in advance. A wrong instruction can cost a farmer a season. |

## 3. How to run it (every time)

The bot only answers while **this laptop is on** and two things are running.

**Step 1: check the Meta token (every 24 h).**
The current token is temporary and **expires at 19:30 on 19 Sept**. When it expires:
1. Open developers.facebook.com → Mungaru app → WhatsApp → API Setup.
2. Click **Generate access token**.
3. Paste it into `.env` as `META_ACCESS_TOKEN=...`.

(To stop doing this every day, make a permanent token; see §5.)

**Step 2: start the bot.** Open PowerShell in `C:\Users\jaip7\Downloads\madhan\act` and run:

```powershell
.\scripts\run.ps1
```

This starts the bot, and a second window with the voice-note engine.

**Step 3: start the public address.** In a second PowerShell window:

```powershell
.\scripts\tunnel.ps1
```

**Step 4: check everything.**

```powershell
.venv\Scripts\python scripts\doctor.py
```

Fix anything marked **FAIL**; each line says how.

**Step 5: test.** Send **hi** from your phone to **+1 555-143-2024**. You should get the menu.

To stop, close the PowerShell windows.

## 4. How to send an advisory (demo)

The forecasting team's system will do this automatically later. For now, from PowerShell in the project
folder:

```powershell
$key = (Select-String -Path .env -Pattern '^ADMIN_API_KEY=(.*)').Matches.Groups[1].Value
$h = @{ 'X-API-Key' = $key }

# 1. Post the advisory. It is held for approval, and the voice note starts rendering.
Invoke-RestMethod -Method Post -Uri http://127.0.0.1:8000/advisories -Headers $h `
  -ContentType 'application/json' -InFile fixtures\advisories\04_bengaluru_south_chilli_demo.json

# 2. Optional: see the Kannada card before approving (open card_url in a browser).
Invoke-RestMethod -Uri "http://127.0.0.1:8000/advisories/7132399B41596969416801_demo_chilli_moisture/preview?lang=kn" -Headers $h

# 3. Approve. Only now does it go to the farmer.
Invoke-RestMethod -Method Post -Uri "http://127.0.0.1:8000/advisories/7132399B41596969416801_demo_chilli_moisture/approve" `
  -Headers $h -ContentType 'application/json' -Body '{"approved_by": "Officer name"}'

# 4. Check delivery.
Invoke-RestMethod -Uri "http://127.0.0.1:8000/dispatch/log?advisory_id=7132399B41596969416801_demo_chilli_moisture" -Headers $h
```

- Example `04_…` goes to farmers in **Bengaluru South** who grow **chilli**, which is your phone.
  Examples `01`–`03` go to Kundgol, Navalgund and Sehore farmers.
- Each advisory can be approved **once**. To send again, change `advisory_id` in the JSON.
- WhatsApp only allows free messages within **24 hours of the farmer's last message**. Before a demo, send
  "hi" from the phone first.

You can also do all of this by clicking, at `http://127.0.0.1:8000/docs`.

## 7. If something goes wrong

| Symptom | Likely cause | Fix |
|---|---|---|
| Bot doesn't reply at all | Bot or tunnel not running, or Meta token expired | Run `doctor.py`; restart `run.ps1` and `tunnel.ps1`; renew the token (§3 step 1) |
| `doctor.py`: "token … 401 / code 190" | Token expired | New token in `.env`, then restart `run.ps1` |
| Advisory "failed: outside 24-hour window" | Farmer hasn't messaged in 24 h | Send "hi" from the phone, then post a new advisory |
| Advisory arrives without a voice note | Voice engine not running, or too slow | Keep the "TTS worker" window open; post early and approve a few minutes later |
| Voice engine window crashes at start | Not enough free memory | Close some apps (Edge, extra VS Code windows) and run `run.ps1` again |
| "Recipient phone number not in allowed list" | Number not verified in Meta | Add it on API Setup → "To" (§5 row 6) |
| ngrok: "domain reserved for another account" | Token and domain from different ngrok accounts | Use the token and domain from the **same** account |
